Mi diario de cefaleas y TA
Webapp personal hecha con Vite, publicada igual que Kakebo y conectada al mismo proyecto de Supabase.
En Supabase, abre SQL Editor y ejecuta una vez `supabase/tabla-diario.sql`.
Sube esta carpeta a un repositorio de GitHub llamado `diario-cefaleas`.
Importa ese repositorio en Vercel. Detecta Vite solo y no necesita variables.
Abre la dirección en el móvil y entra con tu cuenta de Kakebo.
